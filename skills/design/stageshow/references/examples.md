# Examples

Contents:

- Gold examples
- Product studies
- Specimen sheets
- Teaching pairs

Film the closest example before you start. Run everything with `npm install` and `npm run dev` in the skill folder. Each example is `examples/[name]/`.

## Gold examples

The gold examples are the quality bar and the starting points.

| Need | Example | What to learn |
|---|---|---|
| Still or feature card | `static-card` | Quiet hierarchy, a hard crop, one satellite, real words only on the selected customer, its neighbours and the total |
| Dark still | `dark-bento` | One signal said once. Album art keeps it a music app |
| Animated hero, a gesture | `hero-demo` | Five beats, named targets, an annotation, a terminal that comes forward |
| Choreography, no cursor | `payout-flow` | Slow overlapping arrivals, reading time, a payoff that holds |
| Content that changes in place | `choreography` | Retained tracks, soft masks, dependent timing |
| AI answer | `ai-chat` | The question sent, Thinking, the answer streaming in with its height, sources last. No sparkles, no purple |
| AI with cards | `ai-cards` | A multiple-choice card answered and kept as the record, then a card of options booked from its own button |
| Form validation | `form-error` | An error on the field that caused it, cleared by the fix, then the button confirms on itself |
| Drag to reorder | `reorder` | A row lifted by its grip, the others making room, dropped into place |
| Chart scrub | `chart-scrub` | A hairline and dot that follow the pointer, the headline value rolling to the day under it |
| Edit in a table | `table-edit` | A cell edited in place, then the total it feeds rolls a beat later |
| Loading to content | `loading` | A skeleton at the geometry of the content, rows resolving top to bottom, real chrome throughout |
| Dark hero | `dark-hero` | Depth from surface steps on black, one lit colour, a status that changes on its own pill |
| Live collaborators | `presence` | Each person one colour everywhere, names riding their cursors |
| System story | `subscriptions` | A chip flies into a row, MRR rolls, a second scene is the reset |
| Close-up | `close-up` | One control at 1.4x with the chrome of its window, the row whole, a large cursor to match |
| Many of one | `many-of-one` | A grid of one thing off every edge, one tile in focus by depth, the only one with words |
| Fade crop | `fade-crop` | A window that fades out at its foot, over filler |
| Panel over product | `panel-annotation` | A settings panel over the margin of the product, one leader from the setting to what it changed |
| Overlapping windows | `overlap` | A card in front of a window, its edge on the sidebar line of the window |
| Stacked cards | `stacked-cards` | Two components at one width, a small gap, the lower one off the bottom |
| Opposite corners | `opposite-corners` | A bento tile: copy bottom-left, the product hung from the top-right corner |
| Tilted stack | `tilted-stack` | A loose pile of paper at small alternating angles, only the top card has words |
| Corner chip | `corner-chip` | A small chip centred on the corner of a window, half outside |
| Monochrome | `monochrome` | Other companies' products in a row, grayscale, faded at the foot |
| Row of windows | `window-row` | Sessions side by side at one height, focus by depth, only filler cropped |
| Window and phone | `device-pair` | A dashboard and a lock screen that tell one event. The phone straddles over margin, never over the figure |
| Related objects | `story` | An invoice, a plan, a connector, rolling totals |
| Calendar drag | `calendar` | A populated week, one focal event, a measured pickup |
| Free dragging | `freeform-drag` | Grab offset, a measured grid, a drop slot that snaps |
| Phone app | `phone-touch` | A card opens into its screen as one object, and the loop folds back |
| Dynamic Island | `dynamic-island` | One black shape, its content a separate layer |
| Messages | `messages` | Composer, typing, receipts, the lifetime of a bubble |
| Cursors | `cursors`, `cursor-morph`, `cursor-resize` | Five styles, kinds driven by elements, resize edges and corners, no cursor at all |
| Annotations | `annotations` | Leaders, dimensions, flows and a moving target |
| Feature grid | `bento` | One hero, one window, a stat, an object, a diagram |
| Dark ruled grid | `ruled-bento` | Shared rules and technical imagery |
| Consumer grid | `staggered-bento` | Offset tiles, graphic art, physical objects |
| Image-led hero grid | `hero-grid` | Different grounds and materials composed as one picture |
| Upload | `upload` | A file dragged in from the desktop, an upload row whose progress settles as a file row |
| Share | `share` | A share popover: an email becomes a chip, a role menu, a person added to the list |
| Swipe | `swipe` | A phone swipe to archive: press, swipe, a throw at the speed of the finger, the gap closes |

## Product studies

Studies of recognisable products. Read [products.md](products.md) first. Borrow the interaction, never the identity of another product.

| Need | Example | What to learn |
|---|---|---|
| Design tool | `figma` | Canvas selection, a colour picker, a second cursor |
| Issue tracker | `linear` | Command menu and assignment |
| Chat | `slack` | Messages, a reaction, a thread reply |
| Launcher | `raycast` | Search and clipboard history over a blurred desktop |
| Files | `finder`, `finder-glass` | Quick Look over a file list, a file moved into a folder, the same window in frosted glass |
| Music, dark | `spotify` | A dark desktop app with album art |
| Docs and editors | `notion`, `google-docs` | A slash command. A comment and its reply |
| Email | `gmail` | Hover actions, archive, an undo toast |
| Calendar | `google-calendar` | Drag to create an event, the quick-create popup |
| Office | `powerpoint`, `excel` | Slide editing. AutoSum and a chart |
| Browser page | `wikipedia` | Search suggestions in a browser |
| Phone conversations | `telegram`, `imessage` | Native chat apps on an iPhone |
